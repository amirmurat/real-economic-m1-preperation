# MC1 Economics SE — Realistic Offline-Submission Exam Simulator

**Строгий учебный симулятор** Midterm Control 1 по экономике для Software Engineering AlmaU (SDTE, 2026).

> Это учебная копия, **НЕ официальный экзамен**. Она не отправляет ответы, оценки, эссе, нарушения или личные данные в Google Sheets, преподавателю или иной сервер. Внешние CDN используются только для загрузки библиотек интерфейса. Не отправляйте локальный тренировочный токен преподавателю.

## Запуск

После включения GitHub Pages: **https://amirmurat.github.io/real-economic-m1-preperation/**.

Если GitHub Pages ещё не опубликовал страницу, откройте **Settings → Pages**, укажите **Deploy from a branch**, **main**, **/(root)** и нажмите **Save**. Также можно скачать ZIP репозитория и открыть `index.html` локально при подключении к интернету (стили и графики загружаются с CDN).

## Правила, реализованные как у преподавателя

| Событие | Тренировочная реакция | Примечание |
|---|---|---|
| Выделение текста вне полей `input`/`textarea` | Нарушение | Проверяется событие `selectstart` |
| Переключение вкладки, минимизация браузера, уход со страницы | Нарушение | Проверяется `document.visibilitychange` |
| Первое нарушение | Звуковой сигнал, предупреждение и блокировка | В реальном экзамене требуется **пароль преподавателя**. В тренировке вводите **PRACTICE** |
| Второе нарушение в той же попытке | Экран дисквалификации | В тренировке можно начать **НОВУЮ** попытку с нуля |
| Вставка текста в эссе | Запрещена | Оригинальный обработчик `onpaste` |
| Письменное обоснование меньше 60 слов | Завершение недоступно | Проверка длины на этапе финализации |
| Переключение русского/английского | Разрешено | Задания и заполненные ответы сохраняются при смене языка |
| Калькулятор, внутренние вкладки, ползунки | Разрешены | Не являются уходом с сайта |

**Не добавлено выдуманных детекторов.** Например, официальный код не содержит отдельного обработчика, который достоверно определяет нажатие F12; симулятор тоже его не придумывает. Не все браузеры одинаково отправляют `selectstart`/`visibilitychange`.

## Оценивание (логика публичного кода на 13.10.2026)

- Теоретический тест и графики: до **30** баллов.
- Задачи и таблица издержек: до **25** баллов. Баллы таблицы частично зависят от заполненности ячеек, а не от содержательной правильности каждой ячейки.
- Кейс: до **45** баллов. Ползунок до 20, текст до 20, бонус до 5. Текст проверяется простым поиском экономических терминов, наличия числа и минимумом 60 слов.
- После локальной финализации выводятся баллы и **эвристическая** оценка текста. Это не реальное экспертное определение ИИ и не подтверждение оценки преподавателя.

## Начало работы

Выберите своё ФИО в списке. На момент копирования в исходном списке **9 настоящих студенческих записей и одна дополнительная тестовая запись «Бонд Джеймс»** (всего 10 элементов). Для шестого студента код назначает вариант №6 и кейс о чистой монополии. Все вопросы и числовые генераторы соответствуют публичной версии преподавателя; при изменениях в его репозитории понадобится обновление.

## Важное отличие от оригинала

Официальная передача результатов заменена **локальным отчётом**; формируется исключительно тренировочный токен с префиксом `SIMULATION-SE-MC1-`, который нельзя использовать для аттестации. Пароль преподавателя и его сетевой адрес не копируются; первая блокировка разблокируется учебной фразой `PRACTICE`. При повторной блокировке новое прохождение стартует с нуля. Оригинальный контент и основные ограничения остаются без изменений. Публичная доступность репозитория не ограничивает доступ только выбранными людьми.
